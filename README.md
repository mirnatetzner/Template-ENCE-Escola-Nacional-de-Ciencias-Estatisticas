# Template ENCE

Modelo para dissertações e teses da Escola Nacional de Ciências Estatísticas (ENCE).
Este template foi desenvolvido com base em formatações utilizadas em trabalhos acadêmicos da instituição.

Aviso: o presente material não passou por validação institucional oficial.
Trata-se de um modelo elaborado e utilizado pela autora em seu próprio trabalho, disponibilizado aqui para fins de compartilhamento e apoio acadêmico.

## Uso

### Opção 1
O repositório pode ser baixado e depois realizar upload no [Overleaf](https://www.overleaf.com/). 

### Opção 2: Linux 

[Instalar o Latex no Ubutu](https://blog.ufes.br/alessandrosarnaglia/2011/11/24/como-instalar-o-latex-no-ubuntu/)

### Opção 3: Windows

[Instalar o Latex no Windows](https://miktex.org/)


Sugiro para as opções 2 e 3 utilizar o [VSCODE](https://code.visualstudio.com/) com a extensão [latex-workshop.](https://marketplace.visualstudio.com/items?itemName=James-Yu.latex-workshop)
